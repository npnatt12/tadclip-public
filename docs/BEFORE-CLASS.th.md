# ก่อนเข้าคลาส TadClip (ทำก่อนวันเรียน ประมาณ 30 นาที)

คลาสสั้น เราจะใช้เวลาในคลาสตัดคลิปของคุณจริงๆ ไม่ใช่ติดตั้ง ทำ 5 ข้อนี้ให้เสร็จก่อนนะคะ

**1. เช็กเครื่อง** พื้นที่ว่างอย่างน้อย 10 GB และเป็นเครื่องแบบใดแบบหนึ่งนี้
- **Mac:** ชิป Apple (M1 ขึ้นไป) และ macOS 14 ขึ้นไป · ดูที่เมนู  > เกี่ยวกับ Mac เครื่องนี้ (บรรทัด "ชิป" ต้องขึ้นต้นด้วย Apple M)
- **Windows (ทดลอง):** Windows 11 หรือ Windows 10 (เวอร์ชัน 1809 ขึ้นไป) แบบ 64 บิต ชิป Intel หรือ AMD · ดูที่ Settings > System >
  About (บรรทัด "System type" ต้องเป็น 64-bit และ x64) · เครื่องชิป Snapdragon (ARM) ยังใช้ไม่ได้

ถ้าเครื่องไม่ตรง แจ้งในกลุ่ม LINE ก่อนวันเรียน เราคืนเงินให้เต็มจำนวน

**2. สมัคร Claude แบบ Pro** ที่ claude.ai (แบบฟรีใช้ TadClip ไม่ได้) แล้วติดตั้งแอป Claude จาก claude.ai/download
และเข้าสู่ระบบในแอปให้เรียบร้อย

**3. ติดตั้ง TadClip**

**ใช้ Mac:** กด ⌘ + Space พิมพ์ Terminal แล้วกด Enter · วางบรรทัดนี้แล้วกด Enter:

```
curl -fsSL https://raw.githubusercontent.com/npnatt12/tadclip-public/main/install.sh | bash
```

**ใช้ Windows:** กดปุ่ม Windows พิมพ์ PowerShell แล้วกด Enter · วางบรรทัดนี้แล้วกด Enter (ไม่ต้องใช้สิทธิ์ผู้ดูแลเครื่อง):

```
irm https://raw.githubusercontent.com/npnatt12/tadclip-public/main/install.ps1 | iex
```

รอประมาณ 10-30 นาที (Windows อาจถึง 40 นาที) เสียบสายชาร์จ อย่าปิดฝาเครื่อง พอเสร็จหน้า TadClip จะเปิดขึ้นเอง
ถ้าหน้า TadClip ขึ้นปุ่ม "เข้าสู่ระบบ Claude" ให้กดหนึ่งครั้ง · เน็ตหลุด วางบรรทัดเดิมอีกครั้ง ส่วนที่เสร็จแล้วจะข้ามไปเอง

**4. เตรียมคลิป 1-2 คลิป** ถ่ายด้วยมือถือ แนวตั้ง พูดหน้ากล้อง 1-3 นาที พูดผิดพูดใหม่ได้เลย TadClip เลือกเทคที่ดีที่สุดเอง
ส่งคลิปเข้าเครื่อง: Mac ใช้ AirDrop · Windows ส่งผ่าน LINE (เปิด LINE บนคอมฯ แล้วบันทึกไฟล์) หรือสาย USB
เก็บไว้ที่ไหนก็ได้ เช่น เดสก์ท็อป ในคลาสเราจะกดเลือกคลิปจากหน้า TadClip · ถ้ามีโลโก้ร้าน เตรียมไฟล์ไว้ด้วย

**5. เช็กความพร้อม** (หรือพิมพ์ "เช็กความพร้อม TadClip" ในแท็บ Code ของแอป Claude แทนก็ได้)

**ใช้ Mac:** ใน Terminal วางบรรทัดนี้แล้วกด Enter

```
bash ~/.claude/skills/tadclip/scripts/ready.sh
```

**ใช้ Windows:** เปิด PowerShell ใหม่ (กดปุ่ม Windows พิมพ์ PowerShell แล้วกด Enter) วางบรรทัดนี้แล้วกด Enter

```
[Console]::OutputEncoding=[Text.Encoding]::UTF8; & $env:CLAUDE_CODE_GIT_BASH_PATH "$HOME/.claude/skills/tadclip/scripts/ready.sh"
```

รอประมาณ 20 วินาที จะได้บรรทัดที่ขึ้นต้นว่า **TADCLIP READY ✓** คัดลอกบรรทัดนั้นไปวางในกลุ่ม LINE ของคลาส
ถ้าขึ้น **NOT READY** ทำตามข้อที่มีเครื่องหมาย ✗ แล้วเช็กใหม่ ถ้ายังไม่ได้ วางบรรทัดนั้นในกลุ่ม LINE ทีมจะช่วยค่ะ
Windows: ถ้าขึ้นข้อความสีแดงภาษาอังกฤษแทน แปลว่าติดตั้งยังไม่เสร็จ วางบรรทัดติดตั้งในข้อ 3 อีกครั้ง แล้วเช็กใหม่
