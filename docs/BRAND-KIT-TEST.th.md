# ทดสอบ: ใส่แบรนด์ของคุณเอง (ให้ผู้ใช้ทำเอง ห้ามช่วย)

สำหรับคนทดสอบที่ยังไม่เคยใช้ TadClip ใช้เวลา ~5 นาที ผู้ดูแลจดเวลาและคำพูดของผู้ทดสอบ ไม่ชี้ ไม่บอกทาง

**เตรียม:** TadClip ติดตั้งแล้ว มีคลิปพูดหน้ากล้อง 1 คลิป และในมือถือของผู้ทดสอบมีรูปโปรไฟล์ LINE หรือ Facebook ของร้าน/ตัวเอง

**บอกผู้ทดสอบแค่นี้:** "อยากให้คลิปมีโลโก้กับสีของร้านคุณ ลองทำดูเองเลยครับ คิดอะไรอยู่พูดออกมาได้"

| จดอะไร | ผ่านเมื่อ |
|---|---|
| เจอปุ่ม "ใส่แบรนด์ของคุณ" ในหน้า TadClip ได้เอง | ภายใน 1 นาที |
| เอารูปโปรไฟล์จากมือถือมาไว้ในโฟลเดอร์ที่เปิดขึ้นได้ (AirDrop / LINE บนคอม / อีเมล) | ทำได้เอง |
| กลับมาที่หน้า TadClip แล้วเห็นโลโก้กับสีของตัวเองในแถวแบรนด์ | เห็นและพูดว่า "ใช่" |
| ถามคำถามไหม ติดตรงไหน (จดคำพูดตรงๆ) | - |
| ตัดคลิป 1 คลิป ดูคลิปตัวอย่าง แล้วถามว่า "นี่ดูเป็นของร้านคุณไหม" | ตอบว่าใช่ โดยไม่ต้องแก้ |

**หลังทดสอบ:** พิมพ์ "เก็บบันทึก TadClip" แล้วส่งโฟลเดอร์ที่ได้ให้ทีม (ในบันทึกมีเวลาที่ TadClip เห็นแบรนด์ และสิ่งที่มันปรับให้)
